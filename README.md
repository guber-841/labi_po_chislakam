## ЭТО ЛАБА И ВСЕ

Это лаба по инфе и мой первый нормальный проект. Я только только учить такой штуке как численные методы 
Это сырая версия и я хочу ее доработать, чтобы она апроксимировала в полином любой степени

# Сборка 

cmake -S . -B build -G Ninja -DCMAKE_CXX_COMPILER=g++ -DCMAKE_BUILD_TYPE=Debug
cmake --build build && ./build/laba.exe

# Реализация

1. вычисления на double
2. для самой апроксимации используется метод наименьших квадратов
3. для решения слау использован метод квадратных корней
4. рисование графиков с использованием gnuplot
